# Primer us professora (Atenea)

Aquesta carpeta prepara un flux minim per mostrar el sistema just després del primer login de professora.

## Objectiu

Crear, via importacio JSON al panell admin:

1. Un tema: `Administracio de sistemes operatius`
2. Un exercici obligatori de nivell baix (`basic`, tipus `c_file`)
3. Un joc de prova per validar un sumador (`2 2` -> `4`)

## Fitxers JSON (ordre recomanat)

1. `01_tema_admin_sistemas.json`
2. `02_exercici_obligatori_baix.json`
3. `03_joc_prova_sumador.json`

## Exemple d'entregues per provar

A `submissions/` trobaras:

- `ac.c`: exemple valid per a exercici de tipus `c_file`
- `ac.zip`: exemple de projecte zip amb Makefile (util per exercicis `zip_makefile`)

Nota: en aquest primer us l'exercici creat es `c_file`, aixi que la prova directa es pujar `ac.c`.
